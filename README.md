# Eric Emerson Studio

Personal site for [Eric Emerson Tan](https://x.com/EricEmersonTan) — multimedia arts, identity, vectors, and local-first tools.

Live: [eect13.netlify.app](https://eect13.netlify.app)

## What’s in here

- **Studio** — Three.js particle field, theme palettes, geometric vector portrait
- **Atrium** (`/atrium`) — local-first command center (calendar ICS, notes, finance, news)

## Stack

React 19, TanStack Start, Tailwind v4, Three.js, Zustand. Hosted on Netlify.

## Scripts

```bash
npm install
npm run dev        # local studio
npm run build
npm run typecheck
```

Logo mark is still a placeholder (EE).
