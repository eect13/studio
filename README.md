# Eric Emerson Studio

Personal site for [Eric Emerson Tan](https://x.com/EricEmersonTan) — multimedia arts graduate in the Philippines. One personal ambigram, beginner 3D prints, and small tools he uses himself.

Live: [eect13.netlify.app](https://eect13.netlify.app)

## What’s in here

- **Studio** — orbit field, animated trim marks, theme palettes, vector portrait
- **Work** — Hourglass mark, Atrium, Font Manager, Finance Manager, Potion, CourtWire. Public versions refresh from GitHub.
- **Atrium** (`/atrium`) — local-first desk (calendar, notes, finance, news)

## Stack

React 19, TanStack Start, Tailwind v4, Three.js, Zustand. Hosted on Netlify.

## Scripts

```bash
npm install
npm run dev        # local studio
npm run build
npm run typecheck
```
